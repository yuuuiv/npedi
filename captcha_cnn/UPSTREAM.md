# Upstream reference

The fixed-length CNN architecture in `model.py` is adapted for NPEDI from
[`anexplore/cnn_for_captcha`](https://github.com/anexplore/cnn_for_captcha),
pinned to commit `02bfba9c2767ab4842ff8baf45d806fa4cddea3e`.

The upstream project is distributed under the
[Apache License 2.0](https://github.com/anexplore/cnn_for_captcha/blob/02bfba9c2767ab4842ff8baf45d806fa4cddea3e/LICENSE).
This adaptation changes configuration/path handling, dependency versions,
dataset splitting, prediction validation, and whole-CAPTCHA accuracy tracking.
